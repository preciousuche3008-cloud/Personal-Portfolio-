# Mauelle Studios — Personal Portfolio

Welcome to the repository for my personal portfolio website, **Mauelle Studios**.

The portfolio showcases my journey as a T Level Digital Software Development student, with a focus on **UX/UI design and front-end development**.

## About the Project

Mauelle Studios was designed and developed as a personal portfolio to showcase my skills, projects, learning journey and approach to digital design and development.

The project combines a warm, editorial visual style with a clear and user-friendly structure.

## Built With

- HTML
- CSS
- JavaScript
- Figma
- Git & GitHub

## Features

- Responsive multi-page portfolio
- UX/UI-focused project presentation
- Personal journey and learning sections
- Project case study
- Responsive layouts for desktop and mobile
- Contact section
- Accessible and user-focused interface
